# Fonts

Self-hosted WOFF2 subsets from Google Fonts. All three families are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org), which allows embedding on websites.

- `inter-*.woff2` — Inter (variable, 400–700), Rasmus Andersson
- `instrument-serif-italic-*.woff2` — Instrument Serif Italic, Instrument
- `cormorant-italic-cyrillic.woff2` — Cormorant Garamond Medium Italic, Christian Thalmann; used for Cyrillic in the italic headings, because Instrument Serif has no Cyrillic glyphs
