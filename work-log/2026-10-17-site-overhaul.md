# Отчёт о работе: доработка сайта eluZ1uM Technologies

- **Дата:** 17 октября 2026
- **Репозиторий:** github.com/eluZ1uM/eluZ1uM.github.io
- **Ветка:** `claude/happy-galileo-lyx5op` (коммит `401598c`)
- **Статус:** готово и отправлено в ветку; на живой сайт (eluz1um.github.io) ещё НЕ попало — нужно влить ветку в основную

## Задача

Довести сайт студии до хорошего состояния для двух аудиторий — англоязычной и русскоязычной.
Политика конфиденциальности уже существует отдельно и в эту работу не входила.

## Что было не так (до работы)

1. Русская версия подставлялась скриптом после загрузки — поисковики (Google, Яндекс) видели только английский текст.
2. На телефоне не было меню: ссылки в шапке просто скрывались.
3. Если JavaScript не загрузился, страница оставалась пустой (блоки были невидимыми до анимации).
4. Серый текст и метки в светлой теме не проходили норму контрастности (WCAG AA 4,5:1).
5. Курсивный шрифт заголовков (Instrument Serif) не поддерживает кириллицу.
6. Противоречие: «делаем приложения для Windows», хотя Pushup Battle — для iPhone.
7. Scribnox: FB2 упоминался в описании, но отсутствовал в списке тарифа Pro.
8. Одна и та же картинка-превью для соцсетей на всех страницах; не было sitemap, robots.txt, 404, иконки для iPhone.
9. Русский перевод местами звучал как калька.

## Что сделано

### Языки
- Русская версия — отдельные статические страницы: `/ru/`, `/ru/scribnox/`, `/ru/helmavio/`.
- Страницы связаны тегами `hreflang` и `canonical`, у каждой свой заголовок, описание и превью.
- При первом визите браузер с русским языком автоматически попадает на русскую версию; переключатель EN/RU запоминает выбор.
- На русских страницах показываются скриншоты с русским интерфейсом.
- Русский текст переписан там, где звучал неестественно («Точные программы» → «Продуманные программы», «Ваша книга заслуживает быть законченной» → «Пора закончить вашу книгу», «квитанция доказательств» → «отчёт с доказательствами» и др.).
- Для кириллицы в курсивных заголовках подобран похожий шрифт Cormorant Garamond.

### Удобство и доступность
- Меню для телефона (кнопка ☰), закрывается по Esc и при выборе пункта.
- Единые шапка и подвал на всех страницах.
- Контент виден без JavaScript.
- Контраст текста, меток и градиентных заголовков подтянут до нормы в обеих темах.
- Шрифты хранятся на самом сайте — быстрее и без запросов к Google.
- Главные картинки первого экрана грузятся сразу, остальные — по мере прокрутки.

### Поиск и соцсети
- 6 картинок-превью 1200×630 (3 страницы × 2 языка) — `assets/og/`.
- `sitemap.xml` (с языковыми версиями), `robots.txt`, страница 404 на двух языках.
- Иконка для iPhone и PNG-фавикон — `assets/icons/`.
- Разметка schema.org (JSON-LD): организация на главной, приложения на страницах Scribnox и Helmavio.

### Тексты
- Позиционирование: «два приложения для Windows уже в Store, игра для iPhone на подходе».
- Scribnox Pro: добавлен FB2.
- Примечание: цены в фунтах, Store показывает цену в местной валюте.
- Pushup Battle: кнопка «Сообщите мне о запуске» (письмо на почту студии).

## Как устроен сайт теперь

| Файл / папка | Назначение |
|---|---|
| `index.html`, `scribnox/index.html`, `helmavio/index.html` | Английские страницы — ИСХОДНИКИ, правятся вручную |
| `i18n/ru.json` | Русские тексты по ключам |
| `tools/build-ru.mjs` | Генератор русских страниц и sitemap (нужен только Node.js) |
| `ru/…` | Русские страницы — СГЕНЕРИРОВАНЫ, вручную не править |
| `assets/styles.css`, `assets/site.js` | Стили и скрипт (тема, меню, плашки Store, анимация; без слежки) |
| `assets/fonts/`, `assets/og/`, `assets/icons/` | Шрифты, превью для соцсетей, иконки |
| `404.html`, `robots.txt`, `sitemap.xml` | Служебные страницы для браузеров и поисковиков |
| `oauth/` | Служебная страница входа для Helmavio (не менялась) |

### Как менять текст
1. Править английскую страницу (у текста есть атрибут `data-i18n="ключ"`).
2. Поправить русский текст с тем же ключом в `i18n/ru.json`.
3. Выполнить в папке сайта: `node tools/build-ru.mjs` — пересоберёт `/ru/` и `sitemap.xml`; если перевод забыт, выдаст ошибку.
4. Закоммитить все изменения, включая папку `ru/`.

## Как проверялось
- Все страницы на двух языках, на компьютере (1366 px) и телефоне (390 px), в тёмной и светлой теме — скриншоты в браузере Chromium.
- Битых ссылок и картинок нет; ошибок JavaScript нет.
- Автопереход на русский, кнопка EN/RU, мобильное меню, работа без JavaScript — проверены автоматически.
- JSON-LD и sitemap.xml проходят разбор.
- Не проверено: плашки Microsoft Store (сервер get.microsoft.com был недоступен из среды проверки; сработала запасная кнопка) — проверить на живом сайте.
